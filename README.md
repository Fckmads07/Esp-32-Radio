# RadioSense — lecteur de musique intelligent

Projet de l'épreuve finale du cours 420-314 (Cégep Marie-Victorin, automne 2026).

RadioSense est un lecteur de musique autonome sur ESP32 (MicroPython). Il lit des fichiers .wav sur une carte microSD, affiche le titre et le volume sur un LCD 16x2, se met en veille quand personne n'est présent (capteur PIR) et passe en mode NUIT dans une pièce sombre (LDR).
